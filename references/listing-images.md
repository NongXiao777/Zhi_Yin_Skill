# 商品图片工作流

一个可售商品或子体对应一组图。先确认用户提供的是实际销售商品的清晰照片，核对型号、颜色、接口、配件、数量和变体。需要公开参考时，优先查匹配变体的制造商图纸或规格。以同一份已核实的商品资料指导四张图。参考图缺失或与可售内容冲突时标 `IMAGE PENDING`。

| 文件 | 要求 |
|---|---|
| 白底主图 | 以实际商品照片为基准。纯白背景，展示该子体实际收到的商品和数量，遵守适用类目主图要求。 |
| 使用场景图 | 展示已有证据支持的真实用途。方向、固定点、连接、比例符合实际。合成应用图可标为示意。 |
| 细节图 | 展示可见接口、安装位或结构，保持原件的形状、颜色、配件和比例。只标已核实的参数。 |
| 产品尺寸图 | 采用实测或匹配子体的可追溯规格。容差来自资料或测量误差。未核实的产品尺寸保留待确认项。 |

按本项目交付四张独立的 1600×1600 px 文件，逐张展示或下载。辅图标签用美式英语。画面去除促销覆盖层，不添加品牌、Logo、水印、原厂或官方授权暗示。产品实际有永久标识时先解决品牌归属，保持实物真实性。包装预估用于 ERP 和物流预算，商品尺寸图使用产品本身的数据。

生成或编辑时使用当前可用的图像工具及用户提供的参考。逐张检查输出像素、白底主图、可见部件、引线和安装位置、文字、件数与子体一致性。 [Amazon 商品图片要求](https://sellercentral.amazon.com/gp/help/external/G1881?language=en_US)
