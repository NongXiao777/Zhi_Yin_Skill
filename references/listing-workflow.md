# Amazon.com 配件文案工作流

此流程依据 V12.5.3 主规则和对应案例库提炼。需要严格对照项目时，优先读取当前主规则及最新案例库。案例只帮助理解搜索意图、变体风险与可观察的商业信号。商品事实以本次实物、对应变体和直接来源为准。

## 找到可用事实

1. 每次处理一个 SKU 或一个合法父子族。读取现有标题、规格、五点、图片、变体、每个可售款的包装件数和品牌状态。智赢英文介绍为空时，用其余已知资料和联网核验补写空字段。完整 Listing 请求生成全部五个字段。
2. 确认商品身份、搜索意图、接口、安装方式和适用边界。用 exact model 或零件号优先查制造商/监管资料、可追溯供应商规格与 Amazon 当日规则。清晰图片支持可见事实。同系列型号及其他卖家数据只作线索。普通商品做有限的定向核验，找到足够证据即停。
3. 用同一份事实记录驱动文案、变体、图片与 ERP 属性。核实安全、品牌、认证、OE、适配、包装件数和变体冲突。普通未知项省略，夸大表达改成客观事实。只有关键身份、品牌、变体、包装、合规或安全结论未解决时用 `HOLD`，一次最多询问五项，已有答案直接复用。
4. 逐子体核对 SKU、可选组合、随附件数、图片和专属参数。共享 ERP 文案只写全组都成立的事实。单卖配件或不同功能的商品单独判断。选项列表不能证明所有组合都有货，也不证明某个型号覆盖全系列参数。
5. 实物和包装均无品牌时，在后台 Brand 填 `Generic`。在本项目的买家可见文案和关键词中去掉品牌名、原厂/官方/授权暗示、链接与内部审核语。经证实的型号和参考号仍可用于产品识别。确有必要的适配或选型提醒集中写一次。 [Amazon 标题与 Item Highlights](https://sellercentral.amazon.com/seller-forums/discussions/t/145b6d0f-999c-4555-896c-c694bda2e470) · [Amazon 搜索词指南](https://sellercentral.amazon.com/help/hub/reference/external/GNYWHX2TP7C8GXHK)

## 生成并核对交付

以下五项依次各放一个独立的美式英语纯文本代码块，五点合在一块内，每点一行。字符、词数、来源和审核信息放在代码块外。

| 字段 | 内容 |
|---|---|
| Product Title | 核心品名、型号与首要采购规格。美国站非媒体目标上限 75 字符，适用类目更严的限制优先。 |
| Product Highlight | 标题之外的选型、安装或包装信息，最多 125 字符。 |
| Five Bullet Points | 正好五条，各讲一个有事实支持的购买决策点。约 140–220 字符是写作目标，事实有限时可短一些。 |
| Product Description | 4–6 个纯文本小标题，涵盖身份、已知规格、选型/安装和实际包装。简单品通常 140–200 词，技术和多变体品通常 180–300 词。 |
| Backend Search Terms | 最多 249 个 UTF-8 字节。用空格分隔相关技术同义词、缩写或合理检索形式。没有有效增量时允许留空。 |

第六项合并变体与包装、Amazon/ERP 属性、图片问题、质量评分、最终状态、需确认项和简短证据链接。验收看商品可识别、搜索相关、字段分工、自然英文、五点内容、描述可扫读、关键词增量、事实风险、审计用语隔离、父子/包装/图片一致。主规则门槛为 8/10，事实风险、隔离与一致性三项必须通过。用 `COPY`、`COPY WITH OMISSIONS`、`IMAGE PENDING`、`CATEGORY CHECK` 或 `HOLD` 表达当前状态。

## 本地检查与智赢字段

准备一个 JSON 对象，字段为 `product_title`、`product_highlight`、`bullet_points`（五个字符串）、`product_description` 和 `backend_search_terms`。可在 `blocked_brands` 数组中填写本次来源和图片里发现的品牌，或重复用 `--blocked-brand`。填入已判定的 `status`，`HOLD` 稿仍可检查，但不导出待回填文案。

```powershell
python scripts/zhiying.py listing-copy-check --file listing.json --erp-fields
```

检查通过后返回智赢「英语」栏位的产品标题、短标题、要点说明、产品描述和关键词，可用于本地审阅或逐字段回填。CLI 检查文字形状、长度、已列出的品牌和常见关联措辞。商品真值、类目资格、图片和发布状态仍按上方流程核验。包装估算另走 [ERP 商品预览](erp-products.md)。
